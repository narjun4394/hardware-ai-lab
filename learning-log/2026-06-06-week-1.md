# Week 1

## Built

- Started the public Hardware AI Lab.
- Created a synthetic vibration feature baseline with tests.
- Selected the exact starter hardware for the edge vibration monitor.
- Defined the guarded test stand, acquisition target, and safe test classes.

## Measured

- The synthetic fault-like signal raised crest factor from about 1.68 to 5.17.
- The synthetic fault-like signal raised kurtosis from about 1.53 to 5.95.
- The selected ADXL345 starter configuration targets a 3,200 Hz output data
  rate and 1,024-sample windows, or about 0.32 seconds per window.
- The required-parts planning total is USD 128 before tax and shipping.

## Failed

The initial parts list assumed fan speed could be changed without including the
interface needed to do it safely. The corrected design adds a Noctua NA-FC1
controller between the 5 V USB adaptor and fan.

The first fault idea used a rotating imbalance. That would make a visually
dramatic demo, but it adds unnecessary mechanical risk. The initial test plan now
uses guarded changes in speed, mounting compliance, surface, and airflow.

## Learned

- A credible hardware AI project needs an explainable baseline and timing
  evidence before it needs a model.
- Sensor bandwidth limits the faults the device can observe. The affordable
  ADXL345 is suitable for learning the complete workflow, while an IIS3DWB is a
  better future comparison for higher-frequency vibration.
- A bill of materials is incomplete if it omits the fixtures, guards, cables, or
  controls required to reproduce the experiment safely.
