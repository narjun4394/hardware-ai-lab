# Learning Log

Create one short Markdown file per week:

`YYYY-MM-DD-week-N.md`

Use this template:

```markdown
# Week N

## Built

What changed and links to the relevant commits or issues.

## Measured

Numbers, plots, test results, and observations.

## Failed

What did not work and the evidence that changed the plan.

## Learned

New hardware, software, AI, or engineering concepts.

## Next

The smallest testable milestone for the next week.
```
